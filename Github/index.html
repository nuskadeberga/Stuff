Crear una web amb GitHub Pages

Manual fàcil per publicar una web HTML sense perdre't, sense tocar coses estranyes i sense repetir els errors típics.

Idea clau: necessites un repositori públic, un fitxer anomenat exactament index.html i activar GitHub Pages una sola vegada.

Índex ràpid

1. Preparar el fitxer 2. Entrar a GitHub 3. Crear el repositori 4. Pujar el fitxer 5. Activar Pages 6. Veure la URL final 7. Crear webs dins de subcarpetes 8. Actualitzar-la 9. Errors habituals
1

Prepara el fitxer

Abans d'entrar a GitHub

El fitxer principal de la web s'ha de dir exactament:

index.html
No: web.html, prova.html, v25.html o calendari.html.
2

Entra a GitHub

Accedeix amb el teu usuari

Obre GitHub i inicia sessió.

https://github.com
3

Crea un repositori nou

Només la primera vegada
New repository

Després prem:

Create repository
Important: el nom del repositori formarà part de l'adreça final.
4

Puja el fitxer index.html

Publica el contingut inicial

Si el repositori és buit, fes clic a:

uploading an existing file

Si ja té fitxers:

Add file→Upload files

Arrossega index.html i prem:

Commit changes
No reanomenis un fitxer gran des de l'editor de GitHub. És millor que ja arribi amb el nom index.html.
5

Activa GitHub Pages

Només la primera vegada
Settings→Pages

Prem Save.

GitHub triga normalment entre 30 i 60 segons a publicar.
6

Veure i obrir la URL final

Com trobar l'adreça exacta de la teva web

Un cop hagis activat GitHub Pages, torna a:

Settings→ Pages

A l'apartat GitHub Pages apareixerà el botó:

Visit site
Aquesta és la manera més segura: fes clic a Visit site. GitHub obrirà directament la URL final i ja la podràs copiar des de la barra del navegador.

També pots saber l'adreça manualment. Tindrà aquesta estructura:

https://EL-TEU-USUARI.github.io/NOM-DEL-REPOSITORI/

Exemple:

https://nuskadeberga.github.io/operacio2209/

Si crees un index.html dins d’una subcarpeta, l’adreça acabarà amb el nom d’aquesta carpeta. Consulta el pas 7 per veure com fer-ho

https://nuskadeberga.github.io/operacio2209/prova/
Si encara no apareix Visit site: GitHub pot estar publicant la web. Espera uns minuts, torna a carregar la pàgina de Settings → Pages i comprova-ho de nou. Si la web s'obre però no mostra els últims canvis, a Windows prova Ctrl + F5
7

Crear una web dins d'una subcarpeta

Exemple real: ORDITSITRAMES / dashboard

Un mateix repositori pot contenir diverses pàgines web. No cal crear un repositori nou ni tornar a activar GitHub Pages. Cadascuna tindrà un fitxer index.html propi.

ORDITSITRAMES/
├── index.html   ← pàgina principal
└── dashboard/   ← carpeta (icona de carpeta)
    └── index.html   ← pàgina del dashboard

7.1. Crear la carpeta i el fitxer correctament

Entra al repositori ORDITSITRAMES, a la pestanya Code. Selecciona:

Add file→Create new file

Al camp del nom del fitxer, escriu dashboard/ i, després de la barra, index.html. Quan poses la barra, GitHub separa la carpeta del nom del fitxer: a la pantalla pots veure dashboard / index.html. Això és correcte.

Error que ens va passar: escriure només dashboard i confirmar. GitHub crea un fitxer amb aquest nom, no una carpeta. Una icona de document al costat de dashboard confirma l'error; una icona de carpeta confirma que està bé.

7.2. Escriure contingut abans de desar

Sota el nom del fitxer apareix un editor amb el text Enter file contents here. Fes-hi clic, esborra aquest text i enganxa el codi de prova següent:

&lt;!DOCTYPE html&gt;
&lt;html lang="ca"&gt;
&lt;head&gt;
&nbsp;&nbsp;&lt;meta charset="UTF-8"&gt;
&nbsp;&nbsp;&lt;title&gt;Dashboard - Ordits i Trames&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
&nbsp;&nbsp;&lt;h1&gt;Dashboard d'Ordits i Trames&lt;/h1&gt;
&nbsp;&nbsp;&lt;p&gt;La carpeta dashboard funciona correctament!&lt;/p&gt;
&lt;/body&gt;
&lt;/html&gt;

És només una prova. Més endavant podràs substituir aquest contingut pel teu HTML complet.

7.3. Pantalla «Commit changes»

Prem el botó verd Commit changes.... S'obrirà una finestra amb diversos camps:

Com comprovar-ho: a la llista del repositori ha d'aparèixer una carpeta blava anomenada dashboard. Clica-hi: a dins hi ha d'haver index.html.

7.4. Comprovar les dues adreces

Web principal:
https://nuskadeberga.github.io/ORDITSITRAMES/

Dashboard:
https://nuskadeberga.github.io/ORDITSITRAMES/dashboard/

La nova pàgina pot trigar una mica a actualitzar-se. Si el navegador mostra una versió antiga, prova Ctrl + F5 a Windows. Comprova també que Settings → Pages continuï a main / (root).

7.5. Si has creat un fitxer «dashboard» per error

Missatge possible: “Sorry, a file exists where you're trying to create a subdirectory”. Això passa perquè ja existeix un fitxer anomenat dashboard a la mateixa ubicació. GitHub no hi pot crear una carpeta amb el mateix nom.
  1. Si estàs a la finestra de commit amb l'error, prem Cancel i torna a la llista de fitxers del repositori.
  2. Clica el fitxer dashboard (icona de document).
  3. Obre el menú de tres punts de les accions del fitxer i selecciona Delete file. Confirma l'eliminació amb Commit changes directament a main.
  4. Torna a Add file → Create new file i ara escriu dashboard/index.html, afegeix el codi HTML i fes el commit.
No intentis reanomenar el fitxer existent directament a dashboard/index.html: quan dashboard encara és un fitxer, GitHub pot mostrar l'error anterior. Primer elimina el fitxer creat per equivocació. Comprova que estàs eliminant només el fitxer incorrecte, mai l'index.html principal.

7.6. Posar-hi després el dashboard definitiu

Entra a la carpeta dashboard i actualitza aquell index.html amb el teu HTML definitiu. Pots editar-lo si és petit; si ja tens un HTML gran preparat, és preferible pujar-lo des de Add file → Upload files dins de la carpeta, amb el nom index.html, i confirmar la substitució si cal. No substitueixis l'index.html de l'arrel!

Si el dashboard utilitza imatges, CSS, JavaScript, manifest o altres fitxers, també els hauràs de col·locar on correspongui i revisar les rutes relatives. Tenir un index.html dins d'una carpeta no garanteix per si sol que tots els recursos funcionin.

Documentació oficial: Crear fitxers a GitHub · Eliminar fitxers · GitHub Pages.

8

Actualitza la web més endavant

No creïs un altre repositori
Repositori→ Add file→ Upload files→ index.html→ Commit changes
El nou index.html substituirà l'anterior. No cal tornar a activar Pages.
9

Errors habituals

I què vol dir cadascun
Error 404Comprova que la URL i la carpeta siguin correctes, que hi hagi un index.html al lloc adequat i que Pages hagi publicat.
Pàgina en blancEl fitxer pot estar buit, incomplet o tenir un error important.
No es veuen els canvisGitHub encara està publicant o el navegador conserva la versió anterior.
No es pot crear la carpetaSi ja existeix un fitxer amb el mateix nom (com dashboard), primer elimina el fitxer incorrecte. Consulta el pas 7.5.
Botons que no funcionenProva la URL pública a Safari, Chrome o Edge, no dins d'una app de documents.
★

Les 5 normes d'or

El resum que evita gairebé tots els problemes
1El fitxer principal sempre es diu index.html.
2El repositori ha de ser públic.
3No editis fitxers grans directament des de GitHub.
4Després del commit, espera 30-60 segons.
5Prova sempre la URL pública.
