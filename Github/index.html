Crear una web amb GitHub Pages

Manual fàcil per publicar una web HTML sense perdre't, sense tocar coses estranyes i sense repetir els errors típics.

Idea clau: necessites un repositori públic, un fitxer anomenat exactament index.html i activar GitHub Pages una sola vegada.

Índex ràpid

1. Preparar el fitxer 2. Entrar a GitHub 3. Crear el repositori 4. Pujar el fitxer 5. Activar Pages 6. Veure la URL final 7. Actualitzar-la 8. Errors habituals
1

Prepara el fitxer

Abans d'entrar a GitHub

El fitxer principal de la web s'ha de dir exactament:

index.html
No: web.html, prova.html, v25.html o calendari.html.
2

Entra a GitHub

Accedeix amb el teu usuari

Obre GitHub i inicia sessió.

https://github.com
3

Crea un repositori nou

Només la primera vegada
New repository

Després prem:

Create repository
Important: el nom del repositori formarà part de l'adreça final.
4

Puja el fitxer index.html

Publica el contingut inicial

Si el repositori és buit, fes clic a:

uploading an existing file

Si ja té fitxers:

Add file→Upload files

Arrossega index.html i prem:

Commit changes
No reanomenis un fitxer gran des de l'editor de GitHub. És millor que ja arribi amb el nom index.html.
5

Activa GitHub Pages

Només la primera vegada
Settings→Pages

Prem Save.

GitHub triga normalment entre 30 i 60 segons a publicar.
6

Veure i obrir la URL final

Com trobar l'adreça exacta de la teva web

Un cop hagis activat GitHub Pages, torna a:

Settings→ Pages

A l'apartat GitHub Pages apareixerà el botó:

Visit site
Aquesta és la manera més segura: fes clic a Visit site. GitHub obrirà directament la URL final i ja la podràs copiar des de la barra del navegador.

També pots saber l'adreça manualment. Tindrà aquesta estructura:

https://EL-TEU-USUARI.github.io/NOM-DEL-REPOSITORI/

Exemple:

https://nuskadeberga.github.io/operacio2209/

En el cas que s'hagi creat un index a una subcarpeta, l'adreça acabarà amb el nom de la subcarpeta

https://nuskadeberga.github.io/operacio2209/prova/
Si encara no apareix Visit site: GitHub pot estar publicant la web. Espera uns minuts, torna a carregar la pàgina de Settings → Pages i comprova-ho de nou. Si la web s'obre però no mostra els últims canvis, a Windows prova Ctrl + F5
7

Actualitza la web més endavant

No creïs un altre repositori
Repositori→ Add file→ Upload files→ index.html→ Commit changes
El nou index.html substituirà l'anterior. No cal tornar a activar Pages.
8

Errors habituals

I què vol dir cadascun
Error 404No existeix un fitxer anomenat index.html.
Pàgina en blancEl fitxer pot estar buit, incomplet o tenir un error important.
No es veuen els canvisGitHub encara està publicant o el navegador conserva la versió anterior.
Botons que no funcionenProva la URL pública a Safari, Chrome o Edge, no dins d'una app de documents.
★

Les 5 normes d'or

El resum que evita gairebé tots els problemes
1El fitxer principal sempre es diu index.html.
2El repositori ha de ser públic.
3No editis fitxers grans directament des de GitHub.
4Després del commit, espera 30-60 segons.
5Prova sempre la URL pública.
